# 🧠 App_Manager_Pro

Gestionnaire avancé d’applications desktop développé en Python.

App_Manager_Pro permet de :
- lancer des applications rapidement
- gérer plusieurs profils
- scanner automatiquement des logiciels
- centraliser des raccourcis
- organiser des applications gaming/pro/productivité
- créer une interface moderne et personnalisable
